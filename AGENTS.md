# Public Website Runtime — Agent Rules

- This directory mirrors the public runtime repository `Infans-Games/infans-games.github.io`.
- It contains browser-ready artifacts only. Never add credentials, private keys, source-only files, tests, unpublished notes, private databases, or player saves.
- The canonical website source is the private `Infans-Games/official-website` repository. Product sources remain in their own private repositories.
- `CNAME`, the homepage, privacy policy, support page, and unrelated game directories are protected assets. Non-game tools are not published from this repository.
- Publishing is manual. Review the exact added, replaced, and deleted artifact list and obtain Capoo's confirmation before a formal release.
- Keep Pages on `main` from the repository root and verify every public path after release.
